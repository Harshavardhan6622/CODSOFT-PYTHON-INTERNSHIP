# CODSOFT-PYTHON-INTERNSHIP
A collection of Python projects and assignments developed during my CodSoft Internship, demonstrating problem-solving and coding skills.
Task 1: Calculator
    A simple Python calculator that performs basic arithmetic operations.
Users can enter two numbers, choose an operation, and instantly see the result.
Task 2: To-Do List
   A command-line To-Do List app to add, view, complete, and delete tasks.
It helps users stay organized and manage daily goals efficiently.
Task 3: Password Generator
    Generates strong, random passwords using letters, numbers, and symbols.
Users can specify password length to create secure and unique passwords.
Task 4: Contact Book
    A simple contact manager to add, search, update, and delete contacts.
Stores names, phone numbers, emails, and addresses for easy access.
